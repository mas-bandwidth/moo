# Layer 3 notes

Each layer 3 card writes its design note in this directory, beside the code that implements the rule.
`moo-l3-conformance` reads these notes and folds them into `docs/DESIGN.md` ("Layer 3 as built") and
`docs/DETERMINISM.md`, so the two documents stay the agreed state of the layer.
A note names the files it changes, the rule it pins, and the test that holds it.
